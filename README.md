# Ikteder Akhand Udoy

PhD researcher and software builder working across machine learning, computer vision, efficient AI systems, and dependable developer tools. I care about reproducible experiments, transparent limitations, and software that produces inspectable evidence rather than opaque claims.

## Research and engineering interests

- Efficient and hardware-aware machine learning
- Quantization, deployment verification, and model evaluation
- Computer vision and trustworthy dataset tooling
- LLM reliability and structured-output testing
- Native mobile, systems, networking, and developer tools

## Working principles

- Tie claims to tests, metrics, datasets, logs, or reproducible commands.
- Document dataset provenance, model limitations, and experiment conditions.
- Prefer deterministic demos and local-first tools when they make evaluation easier.
- Treat accessibility, safe defaults, and honest failure modes as product requirements.
